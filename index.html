Ulubione serwery Java

Zapisuj adresy serwerów i kopiuj je. Łączenie multiplayer będzie dostępne dopiero po stworzeniu silnika Minecraft Java i logowania.

Konto Microsoft

🔒 Logowanie nie jest jeszcze zaimplementowane. Nie wpisuj hasła Microsoft w NovaCraft. Docelowo użyjemy oficjalnego OAuth z PKCE, bez przechowywania hasła, i sprawdzimy uprawnienia do Minecraft Java.

Stan: niezalogowany. Konto z zakupioną Minecraft Java Edition będzie wymagane do legalnego pobrania i uruchomienia gry.

Kompatybilność wersji

NovaCraft odczytuje oficjalną listę wydań i snapshotów Minecraft. Wyświetlanie wersji nie oznacza jeszcze możliwości uruchomienia jej na iOS 27. Każda wersja będzie wymagała testów Java, LWJGL, grafiki i bibliotek.
